Set up GrowBot on this phone

1. Trust the box (once per phone)

Download the box's certificate, then install it: Settings → Security → Install a certificate → CA certificate. Without it the phone shows a warning and can't install GrowBot as an app.

Download the box's certificate

2. Scan the code from JBrain

On your main phone, open JBrain → GrowBot → Set up another phone, and point this camera at the second code. It opens the creature here.
