jerv · planning & auto-resume
Planning mode is owner-initiated — jerv only drafts a plan when you ask for one, never on its own. You approve it; then it works the checklist across turns — pausing after each step so you can redirect, and auto-continuing if you don't. Only you can approve. Press Run, then watch (or steer) it.

Note (P4): this mock shows the card's visual design, which still holds. In the shipped app the placement changed: the inline card is draft-only (for Approve/Edit), and once approved the in-work plan lives behind the composer's plan pill → popover (same body, in a bottom sheet) so it doesn't crowd the chat; and each auto-continuation step now streams live into the transcript.
