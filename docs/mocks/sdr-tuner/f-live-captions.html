Live captions on the radio

Words are tinted on the same rose→amber→green confidence scale the transcript viewer already uses — the real component imports confidenceColor() from AudioTranscript.tsx rather than defining a second one. Whisper is not a streaming model — it transcribes a finished clip. Live captions therefore mean chunking the live audio, transcribing each piece and appending the text, which lands the words a few seconds behind the sound. These three show what that looks like in the sheet, running against a simulated NOAA weather broadcast with realistic delay. Turn CC on in the sheet to start them.

What this costs, honestly

Delay
Words land one chunk plus inference behind the sound — around 5–8 s. Broadcast CC runs 2–5 s behind, so it is the same order, but it is not instant and cannot be.
Where it runs
On the box. The sidecar already holds the demodulated PCM in Python, so captions tee off that — no second tuner, no audio round-tripping from your phone.
The GPU
The gateway frees whisper when idle, so a steady stream of chunks keeps it resident — sharing the GPU with the chat model for as long as CC is on. That is exactly why it is a toggle and not always-on.
Chunk edges
Cutting mid-word garbles both sides. Cuts land on the quiet gaps the tape already measures, so segments break between transmissions rather than through them.
Reuse
transcribe_audio_chunked already splits, time-shifts and merges whisper output for the video path; the same merge is what stitches these segments. confidenceColor() and transcriptWords() are already exported for the tinting, so captions inherit the scale instead of forking it.
Where confidence comes from
The client already asks whisper for verbose_json, which carries per-token probability — the same field the karaoke transcript colours by. No extra request, no extra model.

The failure mode worth knowing. The repo already notes that “a transcript of an empty band is whisper hallucinating on noise” — pointed at static, it will happily invent fluent sentences. So the tape's own level readings act as the squelch: a segment below the floor is never sent, and the caption line says nothing rather than making something up.
