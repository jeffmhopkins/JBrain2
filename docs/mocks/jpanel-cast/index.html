2 · On the TV (1920×1080, cast as an image or a short clip)

The box renders one 16:9 frame from the notice. With a sound, or the text read aloud, it becomes a short clip with that audio. Google's own media player shows it, so the TVs need no app and no custom receiver. A thin bar runs down the time left.

3 · The idle check: what gets cast over, and what never does

Checked again the instant before every cast. One open question to test on the real sets is whether an app opened with the remote (rather than cast to the TV) reports itself to Cast. If a set does not, it is marked can't tell when busy, and it only takes notices when it is off.
