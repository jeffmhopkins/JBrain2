D — C's shape, and the picture is draggable too. The mode button carries its width, and a second tap on the mode you are already on opens the ladder — so the sheet stays short and every width is still one tap away.

And the shaded box is a control. Drag either handle on the picture and the filter follows, snapping to the same rungs (the ticks along the bottom). Two ways into one value: the popover when you know the number you want, the drag when what you actually want is “narrower than that amber station”. Both write the same setting, so the button relabels as you drag.
