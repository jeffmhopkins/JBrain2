C — The mode button carries the width. No second row. Each mode button shows the width it is currently set to, and tapping the mode you are already on opens its ladder. One control, two levels — the sheet stays short, which matters on a screen that already holds a waterfall, a readout, a transport and captions.

Try it: tap AM (already selected) to open the widths. The argument against this shape is discoverability — nothing on screen says the second tap does anything.
