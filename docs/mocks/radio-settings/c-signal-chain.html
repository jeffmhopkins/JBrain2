C — The chain. A bottom sheet (DESIGN.md's workhorse for a contextual form) that draws the radio as the signal path it actually is: antenna → upconverter → amp → tuner gain → ADC. Two stages are settings and the rest are facts read from what the radio is already described as, so the sheet says which stages you can touch and which merely explain the ones you can.

Its bet is that the owner's problem is a chain problem — an amp they added is driving the tuner too hard — and that a number is easier to choose when you can see what is in front of it. Direct sampling is not an error message here: it is the wire visibly going around the tuner.
