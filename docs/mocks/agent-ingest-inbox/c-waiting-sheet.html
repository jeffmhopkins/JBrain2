Variant C — “waiting on you”, one dot · the two tabs are a sheet you can reach from anywhere
C
C reads Principle 5 — honest status, always visible — as covering this too: if something is waiting on you, the app should not make you go and check. The signal is a single steel dot in the top bar’s status cluster, on every screen, never a number, and simply absent when nothing waits. Tapping it raises a “Waiting on you” sheet carrying the two tabs — Notes, where the question is answerable inline without leaving the screen you were on, and Wiki, where a finding expands in place. The Review tile stays on the launcher as the second door, because a sheet must never be the only way in.

What C commits to. A signal that travels with you: you find out something is waiting while you are already doing something else, which is the only way a question on a nine-day-old note ever gets seen. It costs the most in principle — a persistent mark in global chrome is the closest of the three to the line the owner drew, even without a number — and it costs something in structure too: a sheet is one level deep, so a wiki finding expands in place instead of getting the shipped list → detail with prev/next, and the full Review screen has to keep existing behind the launcher tile for the cases that need it.
