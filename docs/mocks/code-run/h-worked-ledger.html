The ledger is not a new component — it is an existing one, used. .fb-step-cnt already exists, is already styled, and already sits exactly where a result belongs (between the status dot and the caret). It is populated by two tools: search and web_search, which is why your screenshot shows "5 results" on one row and nothing on the other. Every tool filling it is the whole change.

Two proposed additions, marked in the stylesheet: .fb-step-cnt.res (a computed result reads green rather than grey — it is an answer, not a count) and .fb-code for the one step that needs more than a line of text.
