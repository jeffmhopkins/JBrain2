The division of labour. The ƒ marker answers "where did this number come from" without leaving the sentence. The Worked panel answers "what did this turn actually do" — every tool, in order, each with the same argument → result line, and code carrying its full listing. They are not rivals: the panel is the only place a failed call appears, because a failure produces no number to mark.
