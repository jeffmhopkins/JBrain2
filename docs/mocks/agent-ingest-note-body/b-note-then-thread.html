the rule
What you tell me becomes note text; what you ask me doesn't. The agent decides which by whether the reply answers an open question — and it says so on the bubble, immediately, rather than leaving you to find out later that a correction you typed went nowhere.

The failure this design has to avoid: typing an important correction as a passing remark and having it silently not count. The seal makes the outcome visible on the message you just sent. If a reply should have been kept and wasn't, tapping the un-sealed bubble offers keep this in the note — one tap, and it becomes a clarification block dated now.
