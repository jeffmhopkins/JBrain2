Why a deck and not a list. A list of N invites the arithmetic of debt ("14 left"); a five-card deck that ends in a green ring invites completion. The counter reads 2 of 5, not 2 of 137, because the other 132 are not owed anything — each already carries a default and a date, and each is reachable in place (mock A). The end card says so out loud, which is what stops the deck from feeling like a lie.
