C — The log. A recording is not a file, it is something the box heard. Every clip is transcribed on arrival, so the Recordings tab is a search over what was said rather than a column of timestamps — and those transcripts go into the same hybrid search as everything else the box knows.

That changes what the capture control is for. If the value is in the transcript, the box should be catching things while you are not there: Watch this channel arms it to record whenever the squelch opens. You come back to a log, not to an empty list you forgot to fill.

Its cost is honesty about transcription: narrowband radio voice is hard, and a garbled line in a searchable log is worse than no line. Every clip keeps its audio and the transcript is always shown as the machine's reading, never as a record of fact.
